# DEBT TECH 2026 · DEBT NEW

Адаптивный сайт на React 19 / Vite. Новый репозиторий: [IMONsergey/debtupd](https://github.com/IMONsergey/debtupd).

Дизайн: [Figma, страница DEBT NEW](https://www.figma.com/design/lQfOm1SOxe7rAnLQdeCfpA/GPT-ASTRA-TEST?node-id=1405-14239). Рабочие контакты, тарифы, меню, видео, галерея и контракт форм перенесены из `IMONsergey/debt-2026-lite`, production commit `29d23b8` от 23.09.2026. Основной домен этим репозиторием автоматически не переключается.

## Локальный запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
```

Vite проксирует `/api/lead` на действующий сайт. Обычная отправка из локальной формы создаст настоящую заявку. Автотесты перехватывают все отправки и не обращаются к организаторам.

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

## Что реализовано

- Адаптивные сетки 320–2560 px, отдельное мобильное меню, информация из бокового меню в потоке мобильной страницы.
- Все разделы DEBT NEW, 13 спикеров, обе вкладки участников, MULTIPASS / WELCOME, три тарифа, корпоративное участие, 10 конференций, 20 фотографий.
- Исходные портреты, фотографии и космические иллюстрации из Figma. Текст, формы, кнопки и карточки остаются HTML. Логотипы и контур WELCOME — SVG.
- Медленное движение звёзд и свечения в CSS, появление разделов, полёт корабля в меню. `prefers-reduced-motion` отключает анимацию.
- Доступные диалоги: фокус, Escape, возврат к исходной кнопке, блокировка прокрутки; управление вкладками с клавиатуры; свайпы галереи и конференций.
- Формы регистрации, стенда и корпоративного пакета: обязательное согласие, проверка полей, защита от повторной отправки, обработка ошибок и таймаута, сохранение тарифа и UTM.
- Корпоративная скидка: 10% только на третий и четвёртый билеты, 20% на пятый и последующие. Первые два билета оплачиваются полностью.
- Яндекс Метрика `104151247` с параметрами старого сайта включается только на `debt-tech.ru` / `www.debt-tech.ru`. Тестовые просмотры не попадают в основной счётчик.

## Развёртывание

Подробности и порядок переноса: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Два варианта:

1. **Vercel:** импортировать этот репозиторий, framework Vite, build `npm run build`, output `dist`. `vercel.json` направляет `/api/lead` на существующий сервер заявок. Новые секреты в браузер не передаются.
2. **Свой сервер:** `docker compose up -d --build` после заполнения `.env` серверными настройками. Nginx и обработчик заявок работают в одной сети; наружу публикуется только frontend на `127.0.0.1:8080` для существующего HTTPS-прокси.

GitHub Pages пригоден для визуального просмотра. Для работающих заявок ему нужен отдельный API с разрешённым CORS; переписывания `vercel.json` на Pages не выполняются.

## Решения при переносе

Актуальные коммерческие настройки production имеют приоритет над старой подписью в макете: ранняя регистрация — до **1 октября**, цены **44 000 / 49 000 / 66 000 ₽**. В тарифе «Полный» сохранены вечерняя программа и отсутствие Space Disco Afterparty, как на действующем сайте. Уточнения состава тарифа меняются одновременно в `src/content.js` и серверной конфигурации.

Место проведения — **TAU, Москва, Рязанский проспект, 8Ас10**; ссылка карты ведёт на этот адрес. Декоративная карта сохранена из Figma и не заменяет интерактивный маршрут.

Отправку в реальный Bitrix24 / Telegram следует один раз проверить на выбранном тестовом домене с разрешения организаторов перед переключением production. Локальные проверки используют перехваченные ответы, а не настоящие заявки.

## Визуальная приёмка — 29.09.2026

Подробности исправлений, результаты трёх браузерных движков и сравнения до / после: [отчёт аудита](docs/VISUAL_AUDIT_2026-09-29.md).

```bash
npm test
npm run test:e2e
# Dev-сервер должен быть запущен; браузеры устанавливаются через Playwright.
npm run audit:visual
```

`audit:visual` проверяет 24 ширины в Chromium, Firefox и WebKit. Настройки: `QA_BASE_URL`, `QA_BROWSERS`, `QA_WIDTHS`, `QA_SCREENSHOTS`, `QA_OUTPUT`. Пример быстрого прогона опубликованной страницы:

```bash
QA_BASE_URL=https://imonsergey.github.io/debtupd/ \
QA_BROWSERS=chromium QA_WIDTHS=390,768,1440,1920 \
QA_SCREENSHOTS=390,1440 npm run audit:visual
```

JSON и снимки по умолчанию сохраняются в `test-results/visual-audit`. Все запросы к `/api/lead` внутри визуального аудита перехватываются: скрипт не создаёт настоящих заявок. Для уже установленных браузеров поддерживаются `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`, `PLAYWRIGHT_FIREFOX_EXECUTABLE_PATH` и `PLAYWRIGHT_WEBKIT_EXECUTABLE_PATH`.

## Первый экран из отдельных ассетов, прелоадер и отложенное предложение

Актуальный проход: [отчёт по hero и плавности](docs/HERO_MOTION_AUDIT_2026-09-29.md).

Новый первый экран использует предоставленные ассеты в `public/assets/hero`: SVG-логотип, бренд-дымку, планету и неподвижную световую корону. Шейдер Orbit получает геометрию непосредственно от DOM-окружности планеты. WebGL ограничен по разрешению и частоте, останавливается за пределами первого экрана и имеет CSS-замену. Основное звёздное поле по-прежнему выполнено на CSS.

Прелоадер импортирован из main `debt-2026-lite`; баннер раннего бронирования восстановлен по работающей опубликованной версии, поскольку его исходника в этой ветке нет. `TicketOffer.jsx` показывает предложение через 15 секунд, не поверх активной формы, и скрывает его после 1 октября 2026. В меню работает фоновое muted-autoplay видео.

Для проверки готовой сборки с путями GitHub Pages:

```sh
VITE_BASE_PATH=/debtupd/ npm run build
VITE_BASE_PATH=/debtupd/ npm run preview -- --host 127.0.0.1 --port 4173
# В другом терминале:
QA_BASE_URL=http://127.0.0.1:4173/debtupd/ npm run audit:visual
```

## Текущий проход: отзывчивость и плавность

[Отчёт и реальные замеры выполнения](docs/FLUIDITY_AUDIT_2026-09-29.md). Текущая навигация определяется в `src/navigation.js`. Шейдер атмосферы аналитический; объёмный ray-march из предыдущего прохода заменён. Звёзды используют прямые transform-обновления. Появления карточек подготавливаются до входа в экран; показанный контент не скрывается повторно. Все контакты организатора на десктопе собраны в одну строку.

# С конкретным опубликованным URL:
