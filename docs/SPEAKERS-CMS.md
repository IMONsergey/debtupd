# DEBT TECH 2026 — управление спикерами (production)

## Где находится

- Админка: https://debt-tech.ru/programme-admin/ → вкладка «Спикеры».
- Прямой адрес раздела: https://debt-tech.ru/programme-admin/speakers/
- Публичный блок спикеров: https://debt-tech.ru/#speakers
- Предпросмотр черновика: кнопка «Предпросмотр» в разделе «Спикеры»; доступен только после авторизации.

Раздел использует существующий пароль редактора программы. Административные ссылки отсутствуют на публичном сайте.

## Как добавить спикера

1. Войдите в админку и откройте «Спикеры».
2. Нажмите «+ Добавить спикера». Новый человек создаётся скрытым, чтобы недозаполненная карточка случайно не попала на сайт.
3. Укажите имя, должность и организацию.
4. Нажмите «Загрузить изображение» или «Выбрать из библиотеки». Поддерживаются JPG, PNG, WebP до 4 МБ. Библиотека содержит фотографии участников и загруженные файлы, с поиском.
5. Включите «Показывать на сайте».
6. Дождитесь статуса «Черновик сохранён». Нажмите «Предпросмотр», проверьте карточку и «Опубликовать».

Публичный сайт не меняется только от автосохранения. Публикация требует подтверждения. Видимой карточке нужны ФИО, должность и изображение.

## Дополнительные сценарии

- Изменить карточку: выберите спикера, поменяйте текст или фото; опубликуйте.
- Переставить карточки: стрелки или перетаскивание; порядок применяется на сайте после публикации.
- Скрыть человека: выключите «Показывать на сайте». Данные останутся в админке.
- Создать похожего: «Создать копию»; дубликат скрыт и требует нового имени.
- Удалить: только после подтверждения; публичная карточка исчезнет после публикации.
- Восстановить предыдущий список: «Ещё → История публикаций → Восстановить». Восстановление меняет лишь черновик.
- Поиск: поле «Поиск по ФИО и должности» или Ctrl/⌘+K; фильтры «Все», «На сайте», «Скрытые».
- Мобильная версия: «Все спикеры» и «Карточка» переключают рабочие области.

## Техническая архитектура

Данные спикеров изолированы от программы:

- /srv/imon/projects/debt-2026-lite/programme-data/speakers-published.json — опубликованная версия.
- /srv/imon/projects/debt-2026-lite/programme-data/speakers-draft.json — черновик.
- /srv/imon/projects/debt-2026-lite/programme-data/speakers-history/ — история публикаций.
- /srv/imon/projects/debt-2026-lite/programme-data/images/ — библиотека загруженных изображений.

Первоначальная версия содержит 35 актуальных продакшен-спикеров без изменения порядка, изображений или должностей. Публичный API GET /api/speakers читает только опубликованную версию. Приватные операции API — GET /api/speakers/admin, PUT /api/speakers/draft, POST /api/speakers/publish, GET /api/speakers/preview, POST /api/speakers/restore и POST /api/speakers/validate — требуют авторизацию и защиту CSRF и Origin при изменении данных. Загрузка фотографий осуществляется через POST /api/programme/upload, чтение изображений — GET /api/programme/image/....

Публикация списка спикеров не изменяет программу, карточки сессий, тарифы или обработчик заявок. Опубликованная база также используется для выбора людей внутри программы.

Для будущих релизов обязательны server/speakers-schema.mjs, public/data/speakers-seed.json, admin/programme/speakers.html, admin/programme/speakers-editor.js, Caddy-проксирование /api/speakers* на локальную CMS. Перед публикацией резервируйте данные CMS, текущий runtime, конфигурацию Caddy и указатель активного релиза.
