# Проверка переноса интеграций 30.09.2026

Песочница: https://debtupd-sandbox.176.98.177.253.sslip.io/

Основа нового сайта: `debtupd` main `dfc2445`. Сверка с работающим старым проектом: release `20260925T090840Z-29d23b8c7c63`, Node/forms backend и server-only env на том же VPS.

## Подтверждено

- Регистрация, стенд и корпоративный пакет отправлены через интерфейс опубликованной песочницы. По одной заявке каждого вида. Имя во всех трёх: «Тест», комментарий стенда дополнительно поясняет проверку.
- Каждый запрос получил HTTP 200 и реальный `deal_id`. Подтверждение прочитано повторно через `crm.deal.get`, а не только из ответа нашей формы.
- Проверены category 15, стадии `C15:NEW` / `C15:PREPARATION`, связь с контактом и компанией, поля формы, количество участников, source page, все пять UTM для стенда и корпоративной заявки.
- `crm.deal.productrows.get` подтвердил базовую цену и количество для регистрации и корпоративной заявки; для стенда товарные строки отсутствуют, как в старом обработчике.
- Telegram Bot API подтвердил три сообщения. В systemd-журнале сохранены события `telegram_delivered` с ID сообщений. Секреты и содержимое заявок в журнал не записываются.
- Метрика 104151247 загружается и отправляет `/watch/104151247` с адресом песочницы; финальный ответ сервиса 200. Доступ к кабинету статистики для этой проверки не использовался.
- Kinescope возвращает плейлисты HTTP 200 и видео HTTP 206; фон играет с `muted=true`. Модальный плеер использует исходный `content.heroVideo.widgetUrl`, включая повтор ролика.
- Конструктор Яндекс Карт создаёт iframe карты места проведения. Ссылки на программу, политику, телефон, почту и мессенджеры сохранены из исходной конфигурации.
- Серверные/unit-тесты: 11/11. Браузерная регрессия: 76/76, включая 320–2560 px, формы, обработку ошибок, меню, видео и расчёт скидок. Запуск через системный Chrome (скачивание отдельного Chromium Playwright завершалось таймаутом CDN).

## Изоляция

Песочница имеет отдельные release/current/source/env, systemd-сервис и loopback-порт 32027. HTTPS обслуживает новый host block Caddy. Добавлен noindex; секреты скопированы только на сервере, env имеет права 600 root.

После первого развёртывания production сохранил прежний release, SHA-256 HTML и обработчика, а также тот же PID forms-сервиса. Production-домены не переключены. Ветка не настроена на автоматическую публикацию на основной домен.

## Перед переносом

- Получить приёмку новой версии и отдельное разрешение на переключение домена.
- Согласовать цены и дедлайн раннего бронирования после 1 октября.
- Передача в CRM базовой цены/количества оставлена как в исходном сайте. После отдельной правки владельца интерфейс больше не показывает корпоративный расчёт, а открывает общий попап успеха и сохраняет заполненную форму. Автоматическое применение скидки к товарным строкам CRM требует отдельного изменения, это не часть переноса 1:1.
- Обработчик сохраняет исходную модель доставки: сначала Bitrix, затем асинхронное уведомление Telegram. При сетевом таймауте сначала проверять журнал/CRM, не повторять отправку вслепую.
