# DEBT TECH 2026 — редактор программы (песочница)

## Адрес и доступ

Админка доступна только по прямой ссылке:

https://debtupd-sandbox.176.98.177.253.sslip.io/programme-admin/

Ссылки в публичном меню и футере нет. Для работы необходим пароль. Сервер хранит его scrypt-хеш, а сессии защищены CSRF-проверкой. Первоначальный пароль сохранён только в серверном файле:

/srv/imon/projects/debtupd-sandbox/env/programme-admin-initial-password.txt

После смены пароля файл с первоначальным паролем уже не актуален. Не добавляйте секреты в документацию и репозиторий.

## Как работать — три действия

1. **Выберите сцену** наверху экрана. Вкладка «Общие события» содержит регистрацию, открытие и другие события, которые видны на каждой сцене.
2. **Выберите сессию или событие** в списке слева и отредактируйте его справа. На телефоне выберите событие и используйте вкладку «Редактор».
3. **Дождитесь автосохранения, проверьте результат в «Предпросмотре» и нажмите «Опубликовать».** Черновик сохраняется автоматически примерно через две секунды после последней правки. На публичном сайте данные меняются только после отдельного подтверждения публикации.

Верхняя строка различает четыре состояния: «Правки сохраняются автоматически», «Сохраняем…», «Черновик сохранён · ещё не на сайте» и «Все изменения опубликованы». Кнопка «Сохранить» и Cmd/Ctrl+S остаются для принудительного сохранения. При ошибке (например, незаполненное обязательное поле или конфликт двух редакторов) текст ошибки появляется в статусе, а введённые данные сохраняются в полях до исправления. Если редактирование продолжается во время запроса, новые правки не пропадут — редактор сохранит их следующим запросом.

## Частые задачи

**Исправить время:** откройте нужное событие → задайте «Начало» и «Окончание» в 24-часовом формате 10:00. Окончание должно быть позже начала.

**Добавить выступление:** откройте сессию → раздел «Выступления» → «+ Выступление». Нажмите на карточку выступления, чтобы указать тему, примечание и спикеров.

**Добавить спикера:** откройте выступление → «Из программы», если человек уже был на сайте. Можно искать по фамилии или должности; карточка подставит ФИО, должность и фото. Список включает общую базу спикеров сайта. Для нового человека используйте «+ Новый» и заполните поля вручную.

**Поменять фотографию:** в карточке модератора или спикера нажмите «Выбрать фото» / «Заменить фото». Откроется визуальная галерея с поиском по ФИО или названию файла. Изначально показываются фото участников; в фильтре можно выбрать все файлы, загруженные фото или дополнительные изображения. Загрузка JPG/PNG/WebP до 4 МБ доступна в этом же окне. Для пустой карточки можно убрать фото.

**Поменять порядок:** используйте стрелки возле событий в расписании, внутри выступления или возле спикера. События также можно перетаскивать мышью. Для перехода между полями длинной сессии используйте кнопки «Основное», «Модератор», «Выступления».

**Быстро найти событие или человека:** Cmd/Ctrl+K ставит курсор в поиск по расписанию. На телефоне редактор переключится в область расписания автоматически.

**Скрыть элемент:** у сессии/события/выступления снимите флажок «Показывать … на сайте». Данные останутся в черновике и смогут быть возвращены.

**Подготовить ещё не объявленную сцену:** нажмите «Настройки» рядом с названием сцены → в «Состояние программы» выберите «Программа уточняется». События можно редактировать заранее, но посетители их не увидят до переключения в «Показывать расписание» и публикации.

**Перенести или скопировать сессию:** откройте сессию → внизу раскройте «Дополнительные настройки сессии».

**Восстановить опубликованную версию:** «Ещё» → «История публикаций» → «Восстановить». Предыдущая версия попадёт только в черновик. Для вывода на сайт её нужно опубликовать вручную.

**Импортировать/экспортировать программу:** «Ещё» → «Экспорт JSON» или «Импорт JSON». Импорт проверяется на сервере до замены текущих правок. При ошибке данных текущий черновик останется нетронутым.

**Сменить пароль:** «Ещё» → «Настройки программы» → «Сменить пароль». После смены все активные сессии завершаются.

## Архитектура и безопасность

- Публичные данные: GET /api/programme.
- Приватный черновик: GET /api/programme/preview.
- API редактора: GET /api/programme/admin, GET /api/programme/people (каталог спикеров), PUT /api/programme/draft, POST /api/programme/validate, POST /api/programme/publish, POST /api/programme/restore.
- Валидация не сохраняет и не публикует программу. Конфликты версий при записи отклоняются HTTP 409.
- Данные, загруженные изображения и история публикаций хранятся за пределами релизов: /srv/imon/projects/debtupd-sandbox/data.
- Сервис редактора debtupd-sandbox-programme.service изолирован от обработчика заявок. Прокси работает через HTTPS и Caddy.
- Публиковать серверный редактор на основной домен DEBT TECH без отдельного разрешения запрещено.

Новая структура админки не меняет схему программы, адреса API, авторизацию, сохранённые фотографии и опубликованные сведения.
