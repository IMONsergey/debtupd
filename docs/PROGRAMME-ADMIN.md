# DEBT TECH 2026 — редактор программы (песочница)

## Доступ

Редактор открыт только по прямой ссылке `https://debtupd-sandbox.176.98.177.253.sslip.io/programme-admin/`. В меню и футере публичного сайта ссылок нет. Для чтения/изменения черновика требуется пароль; запросы записи дополнительно защищены сессией и CSRF. Пароль хранится на сервере в виде scrypt-хеша.

При первой установке сервер создаёт индивидуальный пароль в файле
`/srv/imon/projects/debtupd-sandbox/env/programme-admin-initial-password.txt`. Пароль **не включён в GitHub и не встроен в сайт**.
На авторизованном Mac его можно посмотреть в терминале:

```bash
ssh debt-2026-lite 'cat /srv/imon/projects/debtupd-sandbox/env/programme-admin-initial-password.txt'
```

После первого входа смените пароль через «Настройки программы».
Не вставляйте пароль в публичные документы и сообщения.


## Ежедневная работа

1. Войдите в редактор.
2. Слева выберите сцену или общее событие; в центре — сессию/выступление; справа исправьте текст, время, модератора, спикеров и фото. На узком экране используйте вкладки «Сцены», «Расписание», «Редактор».
3. Для изменения порядка используйте стрелки или перетаскивайте события в центре. У выступлений и спикеров — отдельные стрелки.
4. Чтобы временно убрать материал с сайта без удаления, снимите отметку «Показывать». Для неопубликованной сцены выберите «Программа уточняется».
5. При необходимости нажмите «Проверить данные» — редактор проверит формат, заполненность и временные интервалы, не меняя опубликованную версию. Затем нажмите «Сохранить черновик». Это **не** изменит публичный сайт.
6. Нажмите «Предпросмотр». Вы увидите сохранённый черновик в оформлении сайта. Для правки вернитесь в редактор.
7. После согласования нажмите «Опубликовать», подтвердите действие. Изменения появляются в песочнице без полной пересборки.

## Частые сценарии

- **Импорт JSON:** перед заменой черновика файл проверяется сервером. Некорректный импорт не удалит текущие данные.\n- **Правки во время сохранения:** редактор сохраняет отправленный снимок, а более свежие изменения оставляет в полях для повторного сохранения.\n- **Новый спикер:** откройте сессию → выступление → «+ Спикер» → ФИО, должность, фото. Если фото уже находится в библиотеке — выберите его из списка; иначе загрузите PNG/JPG/WebP до 4 МБ.
- **Новая сессия:** выберите сцену → «+ Сессия» → время, тема, формат, модератор → «+ Выступление» и спикеры. Сессия отображается в указанном порядке после публикации.
- **Перенос сессии между сценами:** откройте нужную сессию и внизу редактора выберите сцену назначения → «Перенести в выбранную сцену». После переноса проверьте порядок элементов и сохраните черновик.
- **Отмена опубликованных правок:** в блоке «История публикаций» нажмите «Вернуть» у нужной версии. Это загрузит старую версию **в черновик**; проверьте и опубликуйте отдельно.
- **Конфликт редактирования:** если другой редактор уже изменил черновик, сохранение вернёт предупреждение. Обновите страницу, прежде чем повторять изменение.
- **Смена пароля:** «Настройки программы» → «Сменить пароль». После смены все активные сеансы завершаются.

## Хранение данных

Процесс `debtupd-sandbox-programme.service` работает отдельно от форм на `127.0.0.1:32029`. Внешний доступ осуществляется через HTTPS и Caddy. JSON черновика, опубликованной версии, история и фотографии сохраняются под `/srv/imon/projects/debtupd-sandbox/data`, то есть **вне** каталога релизов. Деплой нового сайта их не удаляет.

API: `GET /api/programme` — опубликованные данные; `GET /api/programme/preview` — авторизованный черновик; `GET /api/programme/admin` — редактор; `PUT /api/programme/draft` — сохранение; `POST /api/programme/publish` — публикация; `POST /api/programme/restore` — восстановление в черновик. Удаление данных из админки меняет только черновик, пока не выполнена публикация.

Не добавляйте URL редактора в публичное меню и не переносите админку в продакшен без отдельного разрешения.
