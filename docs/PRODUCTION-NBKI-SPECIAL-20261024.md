# DEBT TECH — НБКИ: специальный партнер (24.10.2026)

## Утвержденная правка

- НБКИ размещен пятой карточкой партнеров непосредственно **перед** ПКО «Интел коллект».
- Порядок локально: ООО «Смарт Бизнес Лаб» → НБКИ → ПКО «Интел коллект».
- Категория НБКИ: **Специальный партнер**.
- Для категории используется существующая планета `planet-special.webp`.
- Количество карточек остается 12, мобильный счетчик: НБКИ `05 / 12`, «Интел коллект» `06 / 12`.
- Оригинальный логотип `nbki.svg`, описание и отсутствие внешней ссылки сохранены.
- Базовый production-релиз: `debtupd-20261023-nbki-marquee-96d51b4`.
- Изменения касаются только фронтенд-данных партнеров и их проверок. CMS программы и спикеров, CRM-формы, тарифы и остальные блоки не меняются.

## Проверка

Проверить 320, 390, 760, 768, 1024, 1180 и 1440 px; порядок и категорию, планету, счетчик и свайпы, отсутствие горизонтального переполнения. Перед выкладкой сохранить точку отката, после — сверить опубликованный сайт и состояние сервисов.
