# Проверка реализации

Проверено 28.09.2026 в Chromium.

- Контрольные ширины: 320, 360, 390, 430, 600, 768, 1024, 1180, 1181, 1280, 1440, 1920, 2560 px.
- Нет горизонтального переполнения документа и обрезания проверяемых заголовков/карточек; 13 спикеров и 3 тарифа присутствуют.
- Обе вкладки участников занимают одну и ту же высоту; фотографии резервируют место до загрузки.
- Мобильное меню открывается, закрывается по Escape, возвращает фокус, прокручивает к началу тарифов.
- Проверены регистрация, стенд и корпоративный пакет с перехваченными HTTP-ответами. Согласие не отмечено заранее; без него запрос не отправляется.
- Тариф, количество, UTM, event_id и form_id передаются в прежнем контракте.
- HTTP 500, `success:false` и HTML вместо JSON не показывают успешную отправку; данные формы сохраняются.
- Скидки проверены на границах 2/3/4/5 участников и для всех трёх цен, включая недопустимые количества.
- Backend без конфигурации отказывает с 503; недопустимые количества и тарифы — 400, без внешних отправок.
- Видео загружается только при открытии; галерея и переключение конференций работают. Фокус и клавиатурные действия доступны.
- При `prefers-reduced-motion` нет движущихся фонов. На localhost/preview нет основного счётчика Метрики.

Это браузерная и программная проверка реализации. Реальная доставка заявки в рабочую CRM, live-метрика после подключения домена, Safari/iOS и итоговый production-перенос требуют проверки на выбранном хостинге. Реальные заявки во время разработки не создавались.
