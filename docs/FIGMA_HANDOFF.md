## Сетка и границы перестроения

**Desktop ≥1181 px**: 15 колонок, 3 под меню, 12 под контент. Нет общего max-width 1440 или 1098.

- edge = clamp(28 px, 2.2vw, 42 px).
- gap = clamp(10 px, 1vw, 16 px).
- column = (availableWidth − 2 × edge − 14 × gap) / 15.
- contentLeft = edge + 3 × column + 3 × gap.
- contentWidth = availableWidth − contentLeft − edge.
- CSS: grid-template-columns:repeat(15,minmax(0,1fr)); content grid-column:4/-1; min-width:0.

В 1440 сохранено округление исходника: edge 32, gap 14, x310, контент 1098. Формула даёт практически те же координаты. 1280: x275,456; 1920: x412,4; 2560: x540,4.

## Визуальный контракт

Сохранить цвета, градиенты, космическую графику, фото, формы карточек, уголки, порядок блоков и иерархию текста. **Bounded — капсом.** Основной текст — IBM Plex Sans. Остальные семейства отдельных слоёв не заменять на похожие.

В макете встречаются:
- Bounded: Regular, Medium, SemiBold; часть начертаний variable с исходными значениями wght ≈466,67 и ≈566,67.
- IBM Plex Sans: Regular, Medium, SemiBold.
- Inter: Light, Regular, Semi Bold, Bold.
- Bebas Neue: Book.
- Roboto Flex: Regular, SemiBold, Bold, с исходными variable axes.

Шрифты доступны в Figma; это не означает, что web-fonts уже находятся в репозитории. Для сайта нужны реальные файлы с кириллицей, правильными весами и проверкой после font loading. Не подменять начертания синтетическими.

Figma cap-height trim и рамка текста не равны CSS line-height. В коде использовать нормальные метрики и рост содержимого; сверять видимый результат с фреймами. Не применять word-break:break-all к заголовкам, ценам, телефонным номерам. Служебные URL могут переноситься в ограниченной области.

Фотографии — cover с сохранением исходного центра кадра. Логотипы — contain, SVG по возможности. Декоративные сложные сцены могут быть растром. UI, меню, формы, подписи и целые секции не экспортировать скриншотами. Портреты спикеров используют пропорцию 357:292 для визуальной области.

Карточки организатора сохраняют сложную нативную композицию исходника; их текст при реализации остаётся HTML. Составные логотипы нельзя растягивать по независимым осям или применять к ним отражённые родительские transforms. Пустые ячейки desktop вокруг ракеты и спутника намеренные.

Обычный фоновый декор: отдельный слой, pointer-events:none. Исключение — композиция космонавта перед тарифами ниже 1181 px: для неё зарезервирована отдельная строка высотой min(470 px, 0.8 × min(contentWidth,650 px)); она участвует в потоке и не закрывает организатора. Обрезать декоративное переполнение на подходящем контейнере, не скрывать таким способом ошибки текстовой вёрстки.
