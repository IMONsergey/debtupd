## Что делаем

После раздела «Спикеры», перед «Об участниках», добавлен раздел «Выставка решений на DEBT TECH 2026» в стиле текущего сайта.

Состав: информационная часть с моей фотографией, показатели, три преимущества, схема площадки с переключателем этажей, увеличение/сброс масштаба, выбор стенда на схеме или из списка, информация о выбранном стенде и заявка.

На первом этаже стенды 1–24, на втором 25–27. Круги с цифрами 1, 2, 3 и т. д. на первом этаже — VIP-переговорные, НЕ выставочные стенды. Они не должны попадать в список стендов. На схеме второго этажа виден нижний этаж фоном; его стенды там не активны.

Используем мои оригинальные SVG. Они уже находятся в репозитории, заново запрашивать вложения не нужно. Геометрия не перерисована, кликабельные области измерены по контурам стендов. SVG нельзя растягивать с нарушением пропорций. При выборе номера из списка схема увеличивается и центрируется на стенде. При смене этажа выбор и масштаб сбрасываются.

Кнопка «Узнать условия» открывает существующую форму бронирования. Комментарий заполняется, например: «Интересует стенд №26, 2-й этаж, выставка решений DEBT TECH 2026.» Комментарий можно редактировать.

Отдельный Vercel-проект debt-tech-exhibition-test, команда cdo-2844s-projects, учётная запись CLI cdo-2844. Это тестовый проект, несмотря на использование --prod для его стабильного адреса. Его URL не связан с основным доменом.

Публикация через Vercel-коннектор оказалась недоступна. Успешно развернули через Remote Desktop Commander на моём MacBook-Pro-erdc.local: там уже настроен вход Vercel CLI. Если этот инструмент подключён в новом аккаунте, сначала найди актуальное устройство через list_devices, проверь `npx --yes vercel@62.1.0 whoami` и работай в отдельном клоне ветки. Не читай и не выводи токены или содержимое файлов авторизации.

Команды из каталога проекта:

```bash
npx --yes vercel@62.1.0 link --yes --project debt-tech-exhibition-test --scope cdo-2844s-projects
npx --yes vercel@62.1.0 deploy --yes --prod --scope cdo-2844s-projects
```

Перед deploy проверь имя связанного проекта и текущую ветку. Не переключайся на другие проекты Vercel. Предыдущий отдельный клон на Mac: /tmp/debt-tech-exhibition.5ti8JE/site, но временный каталог может исчезнуть — при необходимости создай новый. `.env.local` и `.vercel` не коммитить и не публиковать как файлы сайта.

Автосвязь Vercel с GitHub НЕ настроена: Vercel потребовал GitHub Login Connection. Отправка коммита в GitHub сама по себе сайт не обновляет. Используй CLI, если я отдельно не попрошу настроить автопубликацию. Последний runtime deployment: 5dL4akTWJc2nJWCDV5bUYWLB8dk4.
